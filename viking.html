시소 미리보기 (시작 자세 기준)

계산 근거: 단 높이 = 목표 손끝높이 − 최대 리치 (조절 단위로 반올림, 5~75cm). 지지대 높이는 긱블 시뮬 자료의 리치↔지지대 기준표를 보간해 산출(조절 단위로 반올림, 145~185cm). 신장 입력 시 표준표(170cm→리치195/시작98.5 … 200cm→리치250/시작104.5)로 리치·시작 자세를 자동 채웁니다. 실제 측정값이 있으면 리치·시작 자세를 직접 입력하세요.

참고: 원본 긱블 계산기는 비밀번호로 잠겨 있어, 공유된 시뮬 자료의 수치·원리로 재구성했습니다. 실제 한 케이스를 원본과 비교해 값이 맞는지 확인해 주세요.
